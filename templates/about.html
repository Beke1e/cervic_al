PROJECT OVERVIEW

Research into cervical image classification

CerviScope is an interface for exploring a Squeezed Convolutional Neural Network model for classification of precancerous cervical lesions.

What the system does

The model analyzes an uploaded image and returns scores across three configured classes: Negative, Positive, and Suspicious. The scores are model outputs, not a diagnosis or a measure of clinical certainty.

Designed for research use

This application is intended for technical demonstration, research, and education. It has not been established as a screening, diagnostic, or treatment-planning device. Images should only be submitted when you have appropriate authorization to use them.

Image files are processed in memory by this interface and are not saved to an application upload folder. Standard server and infrastructure logs may still apply to the environment hosting the application.
